Tags

A tag only goes into grids once it is complete: every element must have been sorted (ticked = it has the tag, unticked = it doesn't). An element added after the tag was last saved makes it incomplete until you sort it. It needs at least 4 ticked elements, and 40 at most. Mix the types: a grid never has 4 tiles of the same type outside its groups, so a tag whose elements all share one type can't come out.
